# 臺灣常用呼吸系統藥物講義

2026-10-20 · @Lan

本講義依「疾病與用途」整理臺灣臨床常見的呼吸系統用藥：氣喘、慢性阻塞性肺病（COPD）、鼻炎、鎮咳劑與祛痰劑。每類先講機轉與治療原則，再列學名、臺灣商品名與重點，最後以字尾辨識法與臨床情境收尾。

建議讀法：先看第一節，把每個藥歸到「擴張支氣管」或「抗發炎」；氣喘以抗發炎（ICS）為基礎，COPD 以擴張支氣管（LAMA、LABA）為基礎，這是兩者用藥最大的差別。β₂ 致效劑與抗膽鹼藥的受體機轉請見自律神經藥物講義；組織胺與白三烯請見自泌素與平滑肌藥物講義。商品名僅列臺灣常見者，劑量與適應症以仿單及最新 GINA、GOLD 指引為準。

## 一、呼吸道藥物速覽

呼吸道用藥分兩大主軸：**擴張支氣管**（放鬆平滑肌）與**抗發炎**（減少呼吸道腫脹與過度反應）。前者緩解症狀快，後者才能改變病程。

| 主軸 | 作用目標 | 藥物類別 | 代表藥 |
| --- | --- | --- | --- |
| 擴張支氣管 | 刺激 β₂ 受體 → cAMP 上升 → 平滑肌放鬆 | SABA、LABA | Salbutamol、Formoterol、Salmeterol、Indacaterol |
| 擴張支氣管 | 阻斷 M₃ 受體 → 解除迷走神經造成的收縮 | SAMA、LAMA | Ipratropium、Tiotropium、Glycopyrronium |
| 擴張支氣管 | 抑制 PDE、阻斷腺苷受體 | 甲基黃嘌呤類 | Theophylline |
| 抗發炎 | 糖皮質素受體 → 關掉發炎基因 | 吸入型類固醇（ICS）、全身性類固醇 | Budesonide、Fluticasone、Prednisolone |
| 抗發炎 | 阻斷白三烯受體 | LTRA | Montelukast |
| 抗發炎 | 阻斷 IgE 或第二型發炎細胞激素 | 生物製劑 | Omalizumab、Mepolizumab、Dupilumab |
| 抗發炎（COPD） | 抑制 PDE4 | PDE4 抑制劑 | Roflumilast |

吸入劑型的好處是藥物直接到達呼吸道、全身副作用少，但**吸入技巧錯誤是治療失敗最常見的原因之一**：定量噴霧器要配合緩慢深吸並閉氣約 10 秒，可加吸藥輔助器（spacer）；乾粉吸入器則要快速用力吸。

## 二、氣喘治療藥物

氣喘的本質是**呼吸道慢性發炎**（多為嗜酸性球型），所以 **ICS 是所有階段的基礎**。GINA 指引已不建議成人與青少年只用 SABA；**LABA 絕不可單獨使用**，一定要和 ICS 合用。

### 1. 控制藥（每天使用）

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Budesonide | 可滅喘 Pulmicort | ICS | 起效慢（數天到數週）；**吸完漱口**預防鵝口瘡與聲音沙啞；有霧化懸浮液 |
| Fluticasone propionate | 輔舒酮 Flixotide | ICS | 同上 |
| Ciclesonide | Alvesco | ICS（前驅藥） | 在肺部活化，口咽副作用較少 |
| Budesonide／Formoterol | 吸必擴 Symbicort | ICS＋LABA | Formoterol 起效快，可用 **MART**（同一支保養兼緩解） |
| Fluticasone propionate／Salmeterol | 使肺泰 Seretide | ICS＋LABA | Salmeterol 起效慢，**不能用來救急** |
| Fluticasone furoate／Vilanterol | 潤娃易利氣 Relvar | ICS＋LABA | 一天一次 |
| Montelukast | 欣流 Singulair | 白三烯受體拮抗劑 | 運動誘發型、合併過敏性鼻炎、阿斯匹靈加劇型；**FDA 黑框警語：惡夢、情緒改變、自殺意念** |
| Theophylline | Theo-Dur 等 | 甲基黃嘌呤類 | 治療濃度窄；CYP1A2 代謝，受 Ciprofloxacin、吸菸影響；中毒時心律不整、癲癇 |
| Tiotropium | Spiriva Respimat | LAMA | 重度氣喘的加成用藥 |

| --- | --- | --- | --- |
| Salbutamol | 泛得林 Ventolin | SABA | 起效約 5 分鐘、作用 4–6 小時；手抖、心悸、低血鉀 |
| Terbutaline | 特必林 | SABA | 也有口服與注射劑型 |
| Procaterol | 美普清 Meptin | 中效 β₂ 致效劑 | 臺灣兒科常用口服劑型 |
| Ipratropium | Atrovent | SAMA | 急性發作時與 SABA 合併霧化 |
| Budesonide／Formoterol | 吸必擴 Symbicort | ICS-Formoterol | GINA 偏好的緩解藥，每次緩解同時補到 ICS |

| 學名 | 臺灣商品名 | 標的 | 適用 |
| --- | --- | --- | --- |
| Omalizumab | Xolair | IgE | 過敏型重度氣喘、慢性蕁麻疹 |
| Mepolizumab、Benralizumab | Nucala、Fasenra | IL-5 或其受體 | 嗜酸性球型重度氣喘 |

### 4. 急性發作的處理

| 用藥 | 重點 |
| --- | --- |
| SABA（Salbutamol）＋ Ipratropium 霧化 | 第一線；嚴重時可連續給予 |
| 氧氣 | 目標血氧約 93–95% |
| 全身性類固醇（Prednisolone 口服或 Methylprednisolone 靜脈） | 早給，通常口服 5–7 天，減少復發 |
| 硫酸鎂（Magnesium sulfate）靜脈注射 | 重度、對初期治療反應差時；放鬆支氣管平滑肌 |
| Epinephrine 肌肉注射 | 合併過敏性休克，或瀕臨呼吸衰竭時 |

危險徵象：說話只能一字一字講、使用呼吸輔助肌、意識改變、**呼吸音變小甚至「安靜的胸部」**（氣流極少，不是好轉）、血氧持續下降。

## 三、治療慢性阻塞性肺疾病（COPD）藥物

COPD 主要由吸菸造成，氣流阻塞只能部分可逆。用藥以**長效支氣管擴張劑（LAMA、LABA）為基礎**，不像氣喘以 ICS 為基礎；**戒菸是唯一能減緩肺功能惡化的介入**。

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Tiotropium | Spiriva | LAMA | 一天一次；口乾、尿滯留、隅角閉鎖型青光眼慎用 |
| Glycopyrronium、Umeclidinium | 多種（多為複方） | LAMA | 同上 |
| Indacaterol、Olodaterol | 多種（多為複方） | LABA（24 小時型） | COPD 可單用 LABA，和氣喘不同 |
| Indacaterol／Glycopyrronium | Ultibro | LABA＋LAMA | 症狀多、惡化風險高者的主力 |
| Umeclidinium／Vilanterol | Anoro | LAMA＋LABA | 同上 |
| Tiotropium／Olodaterol | Spiolto | LAMA＋LABA | 同上 |
| Fluticasone furoate／Umeclidinium／Vilanterol | Trelegy | ICS＋LAMA＋LABA（三合一） | 反覆惡化且嗜酸性球偏高者 |
| Budesonide／Glycopyrronium／Formoterol | Breztri | ICS＋LAMA＋LABA | 同上 |
| Roflumilast | Daxas | PDE4 抑制劑 | 慢性支氣管炎型、反覆惡化；腹瀉、體重減輕 |
| Azithromycin（長期低劑量） | 多種 | 大環內酯類 | 減少惡化；注意 QT 延長與聽力影響 |

ICS 用於 COPD 的條件：反覆急性惡化、血中嗜酸性球偏高（約 ≥ 300/μL）、或合併氣喘；嗜酸性球低者加 ICS 效果差且**增加肺炎風險**。

急性惡化的處理：SABA＋ SAMA 霧化；口服 Prednisolone 約 5 天；痰量增加且變膿時加抗生素；必要時使用非侵入式陽壓呼吸器（NIV）。**氧氣目標血氧 88–92%**：部分慢性二氧化碳滯留的病人給太多氧氣會使 PaCO₂ 上升、意識變差，但**不可因此對低血氧病人拒給氧氣**。

非藥物治療同樣重要：戒菸（藥物見中樞神經系統藥物講義）、流感與肺炎龊球菌疫苗、肺復原、長期居家氧氣。

## 四、治療鼻炎藥物

過敏性鼻炎以**鼻用類固醇最有效**，對鼻塞、流鼻水、打噴嚏都有效；第二代口服抗組織胺對流鼻水與發癢效果好，但對鼻塞較差。感冒引起的鼻炎則以緩解症狀為主。

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Mometasone | 內舒拿 Nasonex | 鼻用類固醇 | 過敏性鼻炎首選；規則使用數天才達最大效果；噴向外側、避開鼻中隔，減少鼻血 |
| Fluticasone furoate | 艾敏釋 Avamys | 鼻用類固醇 | 同上 |
| Budesonide | Rhinocort 等 | 鼻用類固醇 | 同上 |
| Cetirizine、Levocetirizine、Loratadine、Fexofenadine、Bilastine | 驅異樂 Zyrtec、佳力天 Clarityne、艾來 Allegra 等 | 第二代口服 H₁ 拮抗劑 | 不易嗜睡；一天一次 |
| Azelastine | 多種 | 鼻用抗組織胺 | 起效快；可與鼻用類固醇合用；苦味 |
| Montelukast | 欣流 Singulair | 白三烯受體拮抗劑 | 合併氣喘時可考慮；注意神經精神副作用 |
| Oxymetazoline、Xylometazoline | 多種鼻噴劑 | 鼻用 α 致效劑（鼻塞解除劑） | 效果快，但**連用不超過 3–5 天**，否則反彈性鼻塞（藥物性鼻炎）；幼兒慎用 |
| Pseudoephedrine | 多種感冒藥成分 | 口服鼻塞解除劑（間接擬交感） | 血壓上升、心悸、失眠、尿滯留；受管制（可作製毒原料）；禁與 MAOI 併用 |
| Ipratropium 鼻噴劑 | 依院所而定 | 抗膽鹼藥 | 主要改善水樣鼻水 |
| Cromolyn sodium | 多種 | 肥大細胞穩定劑 | 預防用，需一天多次；安全性高 |
| 生理食鹽水洗鼻 | 多種 | 非藥物 | 減少分泌物與過敏原，安全 |

其他選擇：過敏原免疫療法（減敏治療）是唯一能改變過敏病程的治療，療程數年。鼻窦炎合併鼻息肉的重症病人可用 Dupilumab。

## 五、鎮咳劑

咳嗽是保護性反射，**有痰的咳嗽不宜強力止咳**，否則痰排不出來。鎮咳劑主要用於影響睡眠的乾咳；慢性咳嗽（超過 8 週）要找原因：氣喘、鼻涕倒流、胃食道逆流、ACEI 乾咳。

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Codeine | 止咳複方（多種） | 中樞性、鴉片類 | 作用在延腦咳嗽中樞的 μ 受體；經 CYP2D6 轉成嗎啡，超快速代謝者有呼吸抑制風險，**12 歲以下禁用**；便秘、嗜睡、成癮；管制藥品 |
| Dextromethorphan | 多種感冒藥成分 | 中樞性、非鴉片類（NMDA 拮抗） | 不止痛、一般劑量不成癮；與 SSRI、MAOI 併用可能血清素症候群；大量濫用造成解離與幻覺 |
| Benproperine | 多種 | 中樞兼周邊性、非鴉片類 | 臺灣常見止咳藥成分；口乾、嗜睡 |
| Benzonatate | 臺灣少見 | 周邊性（麻痺肺部牵張受器） | 局部麻醉藥類似物；**膠囊不可咬破**，否則口咽麻痺與嗆到；兒童誤食可致命 |
| Chlorpheniramine | 多種感冒藥成分 | 第一代 H₁ 拮抗劑 | 對鼻涕倒流引起的咳嗽有幫助；嗜睡、口乾 |

說明：不論鴉片類或非鴉片類，對一般感冒引起的急性咳嗽效果都有限。2 歲以下幼兒不建議使用市售咳嗽感冒藥；1 歲以上兒童的夜間咳嗽可以試著吃蜂蜜（1 歲以下禁用，有肉毒桿菌風險）。綜合感冒藥常含多種成分，要注意重複（尤其 Acetaminophen）。

## 六、祛痰劑

祛痰劑分兩類：**化痰劑**改變痰的成分、降低黏稠度；**祛痰劑**增加氣道水分分泌、幫助痰排出。最簡單有效的方法仍是補充足夠水分與有效咳痰。

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Acetylcysteine | 愛克痰 Actein | 化痰劑（切斷黏蛋白雙硫鍵） | 霧化可能誘發支氣管痙攣，氣喘病人小心；有硫磺味；也是 **Acetaminophen 中毒解毒劑** |
| Carbocisteine | Mucodyne 等 | 化痰劑 | 調整黏液成分；可能減少 COPD 惡化 |
| Ambroxol | 沐舒痰 Mucosolvan | 化痰劑 | 增加漿液性分泌與纖毛清除力；罕見嚴重皮膚過敏 |
| Bromhexine | 必嗽平 Bisolvon | 化痰劑 | 在體內代謝成 Ambroxol |
| Guaifenesin | 多種感冒藥成分 | 祛痰劑 | 刺激氣道分泌；證據有限 |
| 高張食鹽水霧化 | 多種 | 滲透性祛痰 | 囊狀纖維化、嬰幼兒細支氣管炎；可能誘發支氣管痙攣，先給 SABA |
| Dornase alfa | Pulmozyme | 重組 DNA 分解酶 | 分解痰中嗜中性球的 DNA；用於囊狀纖維化 |

化痰劑與強效鎮咳劑（尤其 Codeine）一起用會互相抵消：痰變稀了卻咳不出來。年長者、臥床或吞嚥困難的病人痰多時，拍背、姿勢引流與抽痰比藥物更重要。

## 七、字尾辨識法

記住字尾，就能從沒看過的藥名猜出類別。

| 字尾 | 類別 | 例子 |
| --- | --- | --- |
| -terol | β₂ 致效劑 | Formoterol、Salmeterol、Vilanterol、Indacaterol、Olodaterol |
| -tropium | 吸入型抗膽鹼藥 | Ipratropium、Tiotropium、Umeclidinium（-clidinium 為同類） |
| -sonide、-sone | 類固醇 | Budesonide、Ciclesonide、Mometasone、Fluticasone |
| -lukast | 白三烯受體拮抗劑 | Montelukast、Zafirlukast |
| -phylline | 甲基黃嘌呤類 | Theophylline、Aminophylline |
| -milast | PDE4 抑制劑 | Roflumilast |
| -metazoline | 鼻用 α 致效劑 | Oxymetazoline、Xylometazoline |
| -mab | 單株抗體 | Omalizumab、Mepolizumab、Dupilumab |
| -cysteine、-cisteine | 含硫化痰劑 | Acetylcysteine、Carbocisteine |

例外：Salbutamol（美國稱 Albuterol）、Terbutaline 等經典 β₂ 致效劑不完全符合 -terol 規則；Glycopyrronium 是抗膽鹼藥但字尾不同；Dextromethorphan、Ambroxol 等需個別記。

## 八、重點總結與常見臨床情境

呼吸系統用藥最常見的問題是「只用緩解藥、不用控制藥」與「吸入技巧錯誤」。問病史時要問平常用哪一支、多久用一次急救噴劑。

| 臨床情境 | 關鍵藥物 | 處理重點 |
| --- | --- | --- |
| 氣喘急性發作 | Salbutamol ＋ Ipratropium、全身性類固醇 | 霧化、給氧（目標約 93–95%）；注意「安靜的胸部」與意識改變 |
| COPD 急性惡化 | SABA ＋ SAMA、類固醇、抗生素 | **氧氣目標 88–92%**；意識變差要想到二氧化碳滯留 |
| 過敏性休克合併喘鳴 | Epinephrine 肌肉注射 | 不要只靠 Salbutamol 或抗組織胺 |
| 急救噴劑用很兇、每月用完一支 | SABA | 控制不佳的高風險族群，提醒回診調整控制藥 |
| 大量感冒藥後躁動、心悸、高血壓 | Pseudoephedrine、Dextromethorphan、Acetaminophen | 擬交感神經或血清素中毒；提醒院方注意 Acetaminophen 過量 |
| 幼兒誤食咳嗽藥 | Codeine、Benzonatate | 呼吸抑制、癲癇、心律不整；帶藥盒盡速送醫 |

五個最常考也最常出事的警示：

1. 氣喘以 ICS 為基礎，**LABA 絕不可單獨使用**；COPD 則以 LAMA、LABA 為基礎，ICS 只用於特定病人。
2. Symbicort（含 Formoterol）可以保養兼救急，Seretide（含 Salmeterol）不能救急；吸完 ICS 要漱口。
3. Montelukast 有神經精神副作用黑框警語；Theophylline 治療濃度窄、交互作用多。
4. 鼻用 α 致效劑連用超過 3–5 天會反彈性鼻塞；Pseudoephedrine 會升高血壓，且禁與 MAOI 併用。
5. Codeine 經 CYP2D6 轉成嗎啡，12 歲以下禁用；Dextromethorphan 與 SSRI 併用要小心血清素症候群；有痰的咳嗽不宜強力止咳。
