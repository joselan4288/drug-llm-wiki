# 臺灣常用泌尿系統藥物講義

2026-10-20 · @Lan

本講義整理臺灣臨床常見的泌尿系統用藥：利尿劑、泌尿道抗菌劑，以及改變尿液酸鹼度的藥物。每類先講作用部位與機轉，再列學名、臺灣商品名與重點，最後以字尾辨識法與臨床情境收尾。

建議讀法：先看第一節的腎元圖，記住「各類利尿劑卡在腎元的哪一段」，就能推出它們的強度與電解質副作用。攝護腺肥大用藥整理在第五節，α₁ 阻斷劑與膀胱過動用藥的機轉請見自律神經及自泌素與平滑肌藥物講義；利尿劑在高血壓與心衰竭的角色請見心血管藥物講義。商品名僅列臺灣常見者，劑量與適應症以仿單及最新指引為準。

## 一、腎元與利尿劑作用點速覽

> 〔原講義此處有圖：腎元各段與利尿劑作用點 · 5 段腎小管、5 類藥物〕

上排是尿液依序流經的腎小管各段，下排是作用在該段的利尿劑。該段原本吸收的鈉越多，阻斷後利尿越強；但只要作用點在集尿管之前，都會讓鉀流失。

## 二、利尿劑

利尿劑的強度取決於它卡住的那一段「重吸收了多少鈉」：亨利氏環上行支約重吸收 25% 的鈉，所以環路利尿劑最強；遠曲小管約 5–10%，集尿管約 2–5%，所以 Thiazide 與保鉀利尿劑效果較溫和。

| 類別 | 作用部位與機轉 | 代表藥（臺灣商品名） | 主要用途 | 重點副作用 |
| --- | --- | --- | --- | --- |
| 碳酸酐酶抑制劑 | 近曲小管：減少 HCO₃⁻ 重吸收 | Acetazolamide（丹木斯 Diamox） | 青光眼、高山症預防、代謝性鹼中毒 | 代謝性酸中毒、低血鉀、腎結石；磺胺類結構 |
| 滲透性利尿劑 | 近曲小管與亨利氏環下行支：留住水分 | Mannitol（甘露醇） | 顱內壓上升、急性青光眼 | 先擴張血容量，**心衰竭與肺水腫禁用**；脫水、高血鈉 |
| 環路利尿劑 | 亨利氏環上行支粗段：阻斷 Na⁺-K⁺-2Cl⁻ 共同轉運器 | Furosemide（來適泄 Lasix）、Bumetanide | 急性肺水腫、心衰竭與腎病水腫、高血鉀、高血鈣 | 低血鉀、低血鎂、**排鈣**、耳毒性（快速靜脈注射或併用胺基醣苷類）、高尿酸、代謝性鹼中毒 |
| Thiazide 類 | 遠曲小管：阻斷 Na⁺-Cl⁻ 共同轉運器 | Hydrochlorothiazide、Indapamide（納催離 Natrilix）、Chlorthalidone | 高血壓第一線、預防含鈣腎結石、腎性尿崩症 | 低血鉀、**低血鈉（老人最常見）**、**留鈣**、高尿酸、高血糖、高血脂 |
| 保鉀利尿劑（醛固酮拮抗劑） | 集尿管：阻斷醛固酮受體 | Spironolactone（安達通 Aldactone）、Eplerenone（Inspra） | 心衰竭（四大支柱）、肝硬化腹水、原發性醛固酮症 | **高血鉀**；Spironolactone 會造成男性女乳症 |
| 保鉀利尿劑（ENaC 阻斷劑） | 集尿管：阻斷上皮鈉通道 | Amiloride、Triamterene | 常與 Thiazide 合用以抵消低血鉀 | 高血鉀 |
| 血管加壓素拮抗劑 | 集尿管：阻斷 V₂ 受體，只排水不排鈉 | Tolvaptan（Samsca） | SIADH 造成的低血鈉、多囊腎 | **矯正過快可致滲透壓去髓鞘症候群**；肝毒性 |
| SGLT2 抑制劑 | 近曲小管：減少葡萄糖與鈉重吸收 | Empagliflozin（恩排糖 Jardiance）、Dapagliflozin（福適佳 Forxiga） | 糖尿病、心衰竭、慢性腎病 | 生殖泌尿道感染、血糖正常的酮酸中毒 |

電解質記憶重點：環路利尿劑與 Thiazide 都會**低血鉀**，但對鈣相反——**環路排鈣、Thiazide 留鈣**，所以前者可治高血鈣，後者可預防含鈣腎結石；保鉀利尿劑與 ACEI、ARB、鉀補充劑併用容易高血鉀。利尿劑與 NSAID、ACEI／ARB 三者併用即「三重打擊」，容易急性腎損傷；Lithium 與 Thiazide 併用會使 Lithium 濃度上升。Furosemide、Thiazide、Acetazolamide 都是磺胺類結構。

## 三、泌尿道抗菌劑

尿路感染最常見的病原是大腸桿菌。治療原則：**單純性膀胱炎**（非懷孕女性）用短療程口服藥；**腎盂腎炎與複雜性尿路感染**需要全身性抗生素，嚴重時住院靜脈注射；**無症狀菌尿多數不需治療**，孕婦與泌尿道手術前是例外。臺灣大腸桿菌對 Fluoroquinolone 與 TMP-SMX 的抗藥性偏高，選藥應參考當地抗藥性資料與尿液培養。

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Nitrofurantoin | 依院所而定 | 只在尿液達有效濃度的抗菌劑 | 單純膀胱炎首選之一；**不適用腎盂腎炎**（腎組織濃度不足）；腎功能差時無效且毒性增加；長期使用可能肺纖維化、周邊神經病變；尿液變深色 |
| Fosfomycin | 依院所而定 | 細胞壁合成抑制劑 | 單次口服即可；孕婦可用；效果略遜 |
| Trimethoprim／Sulfamethoxazole（TMP-SMX） | 撲菌特 Baktar 等 | 葉酸合成抑制劑 | 抗藥性高；高血鉀、磺胺類過敏（可能 SJS）、G6PD 缺乏者溶血；增強 Warfarin 效果；懷孕初期與末期避免 |
| Cephalexin、Cefuroxime 等頭孢菌素 | 多種 | β-內醯胺類 | 孕婦尿路感染常用；Penicillin 嚴重過敏者小心交叉過敏 |
| Amoxicillin／Clavulanate | 安滅菌 Augmentin | β-內醯胺類加抑制劑 | 孕婦可用；腹瀉 |
| Ciprofloxacin、Levofloxacin | 速博新 Ciproxin、可樂必妥 Cravit | Fluoroquinolone | 用於腎盂腎炎與複雜性感染，**不建議作為單純膀胱炎首選**；FDA 黑框警語：肌腱炎與肌腱斷裂、周邊神經病變、中樞副作用；主動脈瘤風險、QT 延長、血糖異常；孕婦與兒童避免；與含鎂、鋁、鈣、鐵的製劑間隔服用 |
| Methenamine | 依院所而定 | 尿路消毒劑 | 在**酸性尿液**中分解成甲醛殺菌；用於反覆感染的預防，不治療急性感染 |
| Phenazopyridine | Pyridium 等 | 泌尿道局部止痛劑（**不是抗菌藥**） | 緩解排尿灼痛，最多用 2 天；尿液變橘紅色、會染色隱形眼鏡；G6PD 缺乏者溶血、變性血紅素血症 |

孕婦尿路感染要積極治療（可能導致早產），常用頭孢菌素、Amoxicillin／Clavulanate、Fosfomycin；避免 Fluoroquinolone 與 Tetracycline。老人尿路感染常表現為意識混亂或跌倒，而不是典型的頻尿與排尿痛；但老人無症狀菌尿很常見，不能只因尿液檢查異常就認定意識改變是尿路感染造成。

## 四、改變尿液酸鹼度的藥物

改變尿液 pH 有兩個目的：**讓結石溶解或不再形成**，以及**加速排出藥物或毒物**。後者靠「離子捕捉」：弱酸性藥物在鹼性尿中解離成帶電形式，無法穿過腎小管細胞膜被再吸收，就被「關」在尿液裡排出；弱鹼性藥物則在酸性尿中被捕捉。

### 1. 尿液鹼化劑

| 學名 | 臺灣商品名 | 用途 | 重點 |
| --- | --- | --- | --- |
| Sodium bicarbonate（碳酸氫鈉） | 多種 | **水楊酸（Aspirin）中毒**、Phenobarbital 中毒、橫紋肌溶解（用法有爭議）、尿酸結石 | 目標尿液 pH 約 7.5–8；**會加重低血鉀，需同時補鉀**（低血鉀時尿液難以鹼化）；鈉負荷可能加重心衰竭。另外，靜脈注射也用於三環抗憂鬱藥中毒 QRS 變寬（機轉是鈉負荷，不是尿液鹼化） |
| Potassium citrate（檸檬酸鉀） | Urocit-K 等 | 預防尿酸結石、胱胺酸結石、低檸檬酸尿症的含鈣結石 | 檸檬酸會與鈣結合、抑制結石生成；腎功能差或併用保鉀藥物時小心高血鉀；腸胃不適 |
| Sodium citrate | 多種 | 代謝性酸中毒、鹼化尿液 | 含鈉，高血壓與心衰竭者慎用 |
| Acetazolamide | 丹木斯 Diamox | 可鹼化尿液（同時使血液偏酸） | 不用於水楊酸中毒：血液酸化會讓水楊酸進入大腦，惡化中毒 |

### 2. 尿液酸化劑

| 學名 | 用途 | 重點 |
| --- | --- | --- |
| Ammonium chloride（氯化銨） | 代謝性鹼中毒（少用） | 肝功能差者禁用（血氨上升） |
| Methionine、維生素 C | 輔助酸化尿液（效果有限） | 高劑量維生素 C 可能增加草酸鈣結石 |

尿液酸化**已不再用來加速排出弱鹼性毒物**（例如安非他命），因為效果有限，而且酸中毒會加重橫紋肌溶解後的腎損傷。臨床上較常見的酸性尿需求是配合 Methenamine 預防尿路感染。

### 3. 尿液 pH 與結石種類

| 結石 | 容易形成的尿液 | 藥物預防 |
| --- | --- | --- |
| 草酸鈣（最常見） | 與 pH 關係較小 | 多喝水、Thiazide、檸檬酸鉀 |
| 尿酸 | **酸性尿** | 鹼化尿液（檸檬酸鉀）、Allopurinol |
| 胱胺酸 | 酸性尿 | 鹼化尿液、大量喝水 |
| 磷酸鎂銨（感染性結石） | **鹼性尿**（分解尿素的細菌，如變形桿菌） | 治療感染、取出結石 |

## 五、攝護腺肥大用藥

攝護腺肥大造成排尿困難有兩個原因：攝護腺**太緊**（平滑肌收縮，靠 α₁A 受體）與**太大**（腺體增生，靠二氫睪固酮）。α₁ 阻斷劑處理前者、幾天就見效；5α-還原酶抑制劑處理後者、要數個月，兩者常併用。

| 類別 | 學名 | 臺灣商品名 | 機轉 | 重點 |
| --- | --- | --- | --- | --- |
| α₁ 阻斷劑 | Tamsulosin、Doxazosin | Harnalidge、可迅 Doxaben | 放鬆攝護腺與膀胱頸平滑肌 | 幾天內見效；姿勢性低血壓；白內障手術前要告知（詳見自律神經篇） |
| 5α-還原酶抑制劑 | Finasteride | 波斯卡 Proscar | 抑制睪固酮轉成二氫睪固酮，讓攝護腺縮小 | **需 3–6 個月才見效**；PSA 約下降一半，判讀時要乘以 2；性功能副作用；**孕婦不可接觸破碎藥錠**（影響男胎生殖器發育）；低劑量劑型柔沛 Propecia 用於雄性禿 |
|   | Dutasteride | 適尿通 Avodart | 同時抑制兩型 5α-還原酶 | 同上；膠囊不可打開 |
| PDE5 抑制劑 | Tadalafil（每日低劑量） | 犀利士 Cialis | 放鬆攝護腺與膀胱平滑肌 | 合併勃起功能障礙者；禁與硝酸類併用 |
| 抗膽鹼藥、β₃ 促效劑 | Solifenacin、Mirabegron | Vesicare、貝坦利 Betmiga | 放鬆膀胱逼尿肌 | 合併頻尿、急尿時加上；抗膽鹼藥要注意尿滯留 |

會誘發急性尿滯留的藥：第一代抗組織胺與含 Pseudoephedrine 的感冒藥、抗膽鹼藥、三環抗鬱劑、鴉片類。攝護腺肥大的長者吃感冒藥後尿不出來，就是這個原因。

## 六、高血鉀與慢性腎臟病用藥

腎臟衰竭時排不掉鉀與磷，也無法製造紅血球生成素、活化維生素 D。洗腎病人錯過洗腎後出現無力、心搏過緩，要先想到**高血鉀**。

### 1. 高血鉀急救：穩定心臟 → 把鉀推進細胞 → 排出體外

| 步驟 | 藥物 | 機轉 | 起效 | 重點 |
| --- | --- | --- | --- | --- |
| 1. 穩定心臟 | 葡萄糖酸鈣或氯化鈣 | 穩定心肌細胞膜，**不會降低血鉀** | 1–3 分鐘 | 心電圖有變化（T 波高尖、QRS 變寬）時最先給 |
| 2. 把鉀推進細胞 | 胰島素＋葡萄糖 | 活化鈉鉀幫浦 | 15–30 分鐘 | 注意低血糖 |
|   | Salbutamol 霧化 | β₂ 活化鈉鉀幫浦 | 15–30 分鐘 | 心悸、手抖 |
|   | 碳酸氫鈉 | 鹼化使鉀進入細胞 | — | 主要用於合併代謝性酸中毒 |
| 3. 排出體外 | Furosemide | 腎臟排鉀 | 數小時 | 腎臟仍有功能時才有效 |
|   | Polystyrene sulfonate（Kalimate、Kayexalate）、Patiromer、Sodium zirconium cyclosilicate（Lokelma） | 在腸道交換鉀離子後隨糞便排出 | 數小時 | 新藥起效較快、腸胃副作用較少 |
|   | 洗腎 | 直接清除 | 最確實 | 腎衰竭或藥物無效時 |

### 2. 慢性腎臟病與洗腎常用藥

| 問題 | 學名 | 臺灣商品名 | 機轉 | 重點 |
| --- | --- | --- | --- | --- |
| 高血磷 | 碳酸鈣、醋酸鈣 | 多種 | 在腸道結合食物中的磷 | **要隨餐吃**；可能高血鈣 |
|   | Sevelamer | Renvela | 不含鈣的磷結合劑 | 隨餐；便秘、脹氣 |
|   | Lanthanum carbonate | Fosrenol | 不含鈣的磷結合劑 | 隨餐嚼碎服用 |
| 續發性副甲狀腺亢進 | Cinacalcet | 依院所而定 | 擬鈣劑：讓副甲狀腺「以為」血鈣夠高，減少 PTH | 低血鈣、噁心 |
|   | Calcitriol | 羅鈣全 Rocaltrol | 活性維生素 D | 追蹤血鈣與血磷（內分泌篇） |
| 貧血 | Epoetin、Darbepoetin | Eprex、Aranesp | 補充紅血球生成素 | 先補足鐵；血紅素不宜拉太高（血液篇） |

腎臟病人要避免或減量的藥：NSAID、含鎂或鋁的制酸劑與瀉藥、磷酸鈉灌腸劑、Meperidine、Metformin（依腎功能）、多數抗生素與 DOAC（依腎功能調整）。

## 七、字尾辨識法

| 字首/字尾 | 類別 | 例子 |
| --- | --- | --- |
| -semide、-etanide | 環利尿劑 | Furosemide（來適泄 Lasix）、Torsemide、Bumetanide |
| -thiazide | Thiazide 類利尿劑 | Hydrochlorothiazide（例外：Indapamide、Chlorthalidone 為 thiazide-like，但字尾不同） |
| -zolamide | 碳酸酐酶抑制劑 | Acetazolamide（丹木斯 Diamox） |
| -actone、-renone | 醛固酮拮抗劑（保鉀） | Spironolactone（安達通 Aldactone）、Eplerenone |
| -vaptan | 血管加壓素 V2 受體拮抗劑 | Tolvaptan（用於低血鈉、多囊腎） |
| -gliflozin | SGLT2 抑制劑（輕度利尿） | Empagliflozin（恩排糖 Jardiance）、Dapagliflozin（福適佳 Forxiga） |
| -floxacin | Fluoroquinolone 抗菌劑 | Ciprofloxacin、Levofloxacin |
| cef-、ceph- | 頭孢菌素 | Cephalexin、Cefazolin、Ceftriaxone |
| -cillin | 青黴素類 | Amoxicillin/Clavulanate |
| -steride | 5α-還原酶抑制劑 | Finasteride、Dutasteride |

沒有規律字尾、需要直接記的：**Amiloride、Triamterene**（保鉀利尿劑）、**Mannitol**（滲透性利尿劑）、**Nitrofurantoin、Fosfomycin、TMP-SMX**（泌尿道抗菌劑）。

## 八、重點總結與常見臨床情境

| 臨床情境 | 常用藥物 | 要注意什麼 |
| --- | --- | --- |
| 急性肺水腫 | Furosemide 靜脈注射，搭配氧氣、硝化甘油 | 低血壓、低血鉀；作用約 5–30 分鐘內開始 |
| 肝硬化腹水 | Spironolactone ± Furosemide | 高血鉀、男性女乳症 |
| 女性單純膀胱炎 | Nitrofurantoin 5 天，或 Fosfomycin 單次 | 依當地抗藥性；不以 Fluoroquinolone 為首選 |
| 發燒、腰痛的上泌尿道感染（腎盂腎炎） | Ceftriaxone 或依尿液培養結果 | Nitrofurantoin 在腎組織濃度不足，不適用 |
| 阿斯匹靈（水楊酸）中毒 | Sodium bicarbonate 鹼化尿液 | 同時補鉀；監測血中濃度與意識 |
| 尿酸結石 | Potassium citrate + 大量喝水 ± Allopurinol | 腎功能差者小心高血鉀 |

| 洗腎病人高血鉀 | 鈣劑 → 胰島素加葡萄糖、Salbutamol → 降鉀劑或洗腎 | 鈣劑只保護心臟、不降鉀；注意低血糖 |

### 五個必背警示

1. **環利尿劑與 Thiazide 會排鉀**：低血鉀會誘發心律不整，與 Digoxin 併用時毒性增加。到院前遇到服用利尿劑的病人出現無力、心悸，要想到電解質問題。
2. **保鉀利尿劑 + ACEI/ARB 或腎功能差 = 高血鉀**：Spironolactone 與 Lisinopril、Valsartan 併用時要追蹤血鉀；高血鉀可能造成致命心律不整。
3. **長者服用利尿劑容易脫水、姿勢性低血壓與跌倒**：炎熱天氣或腹瀉時風險更高；Thiazide 也會升高血糖、尿酸，可能誘發痛風。
4. **Fluoroquinolone 有肌腱斷裂、QT 延長與血糖異常的風險**：老人與使用類固醇者尤其要小心，因此不作為單純膀胱炎的首選。
5. **鹼化尿液會加重低血鉀**：使用 Sodium bicarbonate 治療中毒時要同時補鉀，否則尿液無法有效鹼化；Acetazolamide 會讓血液偏酸，不可用於水楊酸中毒。
