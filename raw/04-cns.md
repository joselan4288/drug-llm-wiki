# 臺灣常用中樞神經系統藥物講義

2026-10-03 · @Lan

本講義依「藥物類別」整理臺灣臨床最常見的中樞神經系統藥物，共七大類，每項列出學名、臺灣常見商品名與臨床重點。中文商品名各廠牌不同，健保給付與供應可能異動；本章多數藥物屬管制藥品，實際用藥以醫師處方與最新仿單為準。

建議讀法：先讀第一節，把每個藥歸到「它加強或阻斷哪一種傳導物質」；第一代與新一代藥物的差異，多半就是「擋到了多少不該擋的受體」。

## 一、中樞神經傳導物質速覽

大腦靠「麩胺酸踩油門、GABA 踩煞車」維持平衡；其他傳導物質各管一件事。

| 傳導物質 | 角色 | 太少 | 太多 | 代表藥物 |
| --- | --- | --- | --- | --- |
| 麩胺酸 | 主要興奮（油門） | 意識變差 | 癲癇、神經死亡 | Ketamine、Memantine（拮抗 NMDA） |
| GABA | 主要抑制（煞車） | 焦慮、失眠、癲癇 | 昏睡、呼吸抑制 | BZD、Propofol、酒精（增強） |
| 多巴胺 | 動作、獎賞、動機 | 巴金森氏症 | 幻覺、妄想 | 左旋多巴（補）、抗精神病藥（擋） |
| 血清素 | 情緒、睡眠、食慾 | 憂鬱、焦慮 | 血清素症候群 | SSRI（增加） |
| 正腎上腺素 | 警覺、注意力 | 疲倦、憂鬱 | 焦慮、心跳快 | SNRI（增加） |
| 乙酰膽鹼 | 記憶、注意力 | 失智、譫妄 | — | 膽鹼酯酶抑制劑（增加） |
| 組織胺 | 清醒 | 嗜睡 | — | 第一代抗組織胺（擋→嗜睡） |
| 腦內啡 | 內生性止痛 | 疼痛敏感 | — | 鴉片類（模仿） |

藥物能否進入中樞取決於血腦障壁：脂溶性高、分子小、不帶電荷者較易通過。

## 二、鎮靜安眠藥

BZD 與 Z-drugs 都增強 GABA-A 受體；BZD 增加氯離子通道「開放頻率」，因需要 GABA 在場而有天花板效應，單獨過量少致死。失眠第一線治療是認知行為治療（CBT-I），藥物為短期輔助。

### 1. 苯二氮平類（BZD）

| 學名 | 臺灣商品名 | 半衰期 | 重點 |
| --- | --- | --- | --- |
| Lorazepam | 安定文 Ativan | 中（12–18 h） | 癲癇重積 IV 首選；只經葡萄糖醛酸化，肝病與老人首選 |
| Diazepam | Valium | 長（含活性代謝物） | 肌肉痙攣、酒精戒斷；兒童有直腸劑型 |
| Midazolam | Dormicum | 極短（1.5–3 h） | 麻醉誘導、程序鎮靜、無 IV 時肌注終止癲癇 |
| Alprazolam | 贊安諾 Xanax | 短中 | 恐慌症；依賴性與反彈焦慮最明顯 |
| Clonazepam | 利福全 Rivotril | 長（18–50 h） | 肌陣攣癲癇、REM 睡眠行為障礙、恐慌症 |
| Estazolam | 悠樂丁 Eurodin | 中 | 臺灣常用安眠藥 |
| Brotizolam | 戀多眠 Lendormin | 短 | 入睡困難 |
| Flunitrazepam | FM2（Rohypnol） | 中長 | 第三級管制；曾被濾用於犯罪 |

### 2. 其他助眠藥

| 學名 | 臺灣商品名 | 機轉 | 重點 |
| --- | --- | --- | --- |
| Zolpidem | 使蒂諾斯 Stilnox | Z-drug（GABA-A） | 入睡困難；夢遊、夢食、失憶行為需警覺；第四級管制 |
| Zopiclone | 宜眠安 Imovane | Z-drug | 口中苦味 |
| Trazodone | 美舒鬱 Mesyrel | 抗憂鬱藥（5-HT₂A 拮抗） | 低劑量常用於助眠；姿勢性低血壓、罕見陰莖異常勃起 |
| Ramelteon | Rozerem | 褪黑激素受體促效 | 無依賴性，效果溫和 |

共同風險：與鴉片類、酒精、Gabapentinoid 併用有協同性呼吸抑制；老人跌倒與譫妄；BZD 與酒精的戒斷可致癲癇，不可突然停藥。BZD 過量的逆轉劑 Flumazenil 可能誘發抽搐，實務少用。

## 三、抗癲癇藥

選藥依發作型態：廣效藥對局部與全般性發作皆可；鈉通道窄效藥只適合局部性發作，用於失神或肌陣攣發作會惡化。約三分之二病人單一藥物即可控制。

### 1. 廣效藥

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Levetiracetam | 優閒 Keppra | 結合 SV2A；幾乎無交互作用、有靜脈劑型；副作用易怒、憂鬱 |
| Valproate | 帝拔癲 Depakine | 全般性發作最有效；育齡女性應避免（致畸、胎兒智力影響）；肝毒性、高血氨 |
| Lamotrigine | 樂命達 Lamictal | 育齡女性首選之一；必須極緩慢加量防 SJS；與 Valproate 併用加量更慢 |
| Topiramate | 妥泰 Topamax | 也用於偏頭痛預防；認知遲鈍、腎結石、閉角性青光眼 |

### 2. 鈉通道窄效藥（局部性發作）

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Carbamazepine | 癲通 Tegretol | 用藥前驗 HLA-B*15:02（SJS/TEN）；強力 CYP 誘導劑、低血鈉；也治三叉神經痛 |
| Oxcarbazepine | 除癲達 Trileptal | 交互作用較少；低血鈉更常見 |
| Phenytoin | Dilantin | 零階動力學，劑量小變化濃度大跳；牙齦增生、眼球震顫、共濟失調 |
| Lacosamide | Vimpat | 交互作用少、有靜脈劑型；注意 PR 間期延長 |

### 3. 其他

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Gabapentin | 鎮頑癲 Neurontin | 結合鈣通道 α2δ；現多用於神經痛；完全經腎排除 |
| Clonazepam | 利福全 Rivotril | 肌陣攣、失張力發作；會產生耐受 |
| Ethosuximide | Zarontin | 兒童失神發作首選 |
| Zonisamide | 依院所而定 | 阻斷鈉通道與 T 型鈣通道；屬磺胺類結構（磺胺過敏慎用）；腎結石、代謝性酸中毒、兒童少汗與體溫過高；日本也用於巴金森氏症輔助 |
| Phenobarbital | Phenobarbital | 老藥，鎮靜強、CYP 誘導 |

癲癇重積狀態（發作≥ 5 分鐘）：第一線 BZD（有 IV 用 Lorazepam，無 IV 用 Midazolam 肌注），劑量要給足；第二線 Levetiracetam、Valproate 或 Fosphenytoin。不可自行停藥。

## 四、抗憂鬱藥與情緒穩定劑

抗憂鬱藥多半增加血清素或正腎上腺素；效果需 2–4 週才出現，副作用則往往先出現。SSRI 為多數憂鬱症與焦慮症的第一線。

### 1. 抗憂鬱藥

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Fluoxetine | 百憂解 Prozac | SSRI | 半衰期最長，停藥戒斷少；CYP2D6 抑制 |
| Sertraline | 樂復得 Zoloft | SSRI | 心血管疾病者較安全 |
| Escitalopram | 立普能 Lexapro | SSRI | 交互作用少；高劑量注意 QT |
| Paroxetine | 克憂果 Seroxat | SSRI | 停藥戒斷明顯、抗膽鹼作用較多 |
| Venlafaxine | 速悅 Efexor | SNRI | 高劑量可升血壓 |
| Duloxetine | 千憂解 Cymbalta | SNRI | 也治糖尿病神經病變與慢性疼痛 |
| Mirtazapine | 樂活憂 Remeron | NaSSA | 助眠、增加食慾與體重；性副作用少 |
| Bupropion | 威博雋 Wellbutrin | NDRI | 不會性副作用、也用於戒菸；降低癲癇閾值 |
| Vortioxetine | Brintellix | 多模式 | 較新；噁心常見 |
| Amitriptyline | — | 三環抗鬱劑 | 現多用於神經痛、偏頭痛預防；過量致命（QRS 增寬→碳酸氫鈉） |

重要警語：25 歲以下用藥初期需警覺自殺意念；與 Tramadol、Triptan、MAOI、DXM 併用注意血清素症候群；SSRI 增加出血風險（尤其併用 NSAID、抗凝血劑）；老人低血鈉。不可突然停藥。

### 2. 情緒穩定劑（雙相情緒障礙）

| --- | --- | --- |

| Valproate | 帝拔癲 Depakine | 躁症急性期與維持 |
| Lamotrigine | 樂命達 Lamictal | 偏向預防鬱期 |

## 五、抗精神病藥

共同機轉是阻斷多巴胺 D₂ 受體；第一代（典型）錐體外副作用多，第二代（非典型）另擋 5-HT₂A，錐體外副作用較少但代謝副作用較多。

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Haloperidol | Haldol | 第一代 | 急性躁動、譫妄；錐體外副作用與 QT 延長 |
| Chlorpromazine | Wintermin | 第一代 | 鎮靜強、低血壓、抗膽鹼 |
| Risperidone | 理思必妥 Risperdal | 第二代 | 高劑量有錐體外副作用、泌乳激素上升 |
| Paliperidone | Invega | 第二代 | Risperidone 代謝物；有長效針劑 |
| Olanzapine | 金普薩 Zyprexa | 第二代 | 體重增加、血糖血脂上升明顯 |
| Quetiapine | 思樂康 Seroquel | 第二代 | 鎮靜、姿勢性低血壓；巴金森氏症精神症狀可用 |
| Aripiprazole | 安立復 Abilify | 第二代（部分促效） | 代謝副作用較少；靜坐不能常見 |
| Clozapine | Clozaril | 第二代 | 頑固型思覺失調症最有效；顆粒球缺乏需定期驗白血球、心肌炎、癲癇 |

主要副作用與處置：

| 副作用 | 說明 |
| --- | --- |
| 急性肌張力不全 | 頭頸扭轉、眼球上吐；用 Diphenhydramine 或 Benztropine |
| 靜坐不能 | 坐立難安；可用 Propranolol |
| 藥物性巴金森症候群 | 動作遲緩、僵硬、手抖 |
| 遲發性運動不能 | 長期使用後口舌不自主動作，可能不可逆 |
| 抗精神病藥惡性症候群 | 高燒、肌肉僵硬、意識改變、CK 上升；急症 |
| 代謝症候群 | 體重、血糖、血脂上升（Olanzapine、Clozapine 最明顯） |
| QT 延長 | Haloperidol 靜脈、部分第二代 |

失智症老人使用抗精神病藥有增加死亡率的黑框警語；路易氏體失智症病人對抗精神病藥極度敏感。

## 六、巴金森氏症與失智症用藥

巴金森氏症是多巴胺不足，治療方向是「補多巴胺」；阿茲海默症與乙酰膽鹼不足、麩胺酸過度活化有關。

### 1. 巴金森氏症

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Levodopa/Carbidopa | 心寧美 Sinemet | 多巴胺前驅物 | 最有效；Carbidopa 只擋周邊轉換；空腹服用較佳（蛋白質競爭吸收） |
| Levodopa/Benserazide | 美道普 Madopar | 多巴胺前驅物 | 同上 |
| Levodopa/Carbidopa/Entacapone | Stalevo | 三合一 | 延長藥效 |
| Pramipexole | Mirapex | 多巴胺促效劑 | 衝動控制障礙、突然入睡 |
| Ropinirole | Requip | 多巴胺促效劑 | 同上；也治不寧腿 |
| Rotigotine | Neupro | 多巴胺促效劑貼片 | 無法口服時可用 |
| Rasagiline、Selegiline | Azilect | MAO-B 抑制劑 | 減少腦內多巴胺分解 |
| Entacapone | Comtan | COMT 抑制劑 | 延長左旋多巴作用 |
| Amantadine | Symmetrel | NMDA 拮抗等 | 對異動症最有效的口服藥 |
| Trihexyphenidyl | Artane | 抗膽鹼 | 年輕震顫型；老人易譫妄 |

注意：左旋多巴不可突然停藥（類惡性症候群）；止吐避免 Metoclopramide，改用 Domperidone；精神症狀需用抗精神病藥時選 Quetiapine 或 Clozapine。

失智症病人應避免抗膽鹼藥物（第一代抗組織胺、膀胱過動藥），會抵銷治療並加重認知障礙。

## 七、鴉片類與神經病變性疼痛用藥

鴉片類作用於 μ 受體，止痛與呼吸抑制走同一條路；神經病變性疼痛對 NSAID 反應差，需用 Gabapentinoid、抗憂鬱藥等。

### 1. 鴉片類

| 學名 | 臺灣商品名 | 強度 | 重點 |
| --- | --- | --- | --- |
| Tramadol | Tramal；複方 Ultracet | 弱 | 需 CYP2D6 活化；血清素症候群、降低癲癇閾值 |
| Codeine | 多為止咳複方 | 弱 | 12 歲以下與哺乳婦女禁用（CYP2D6 超快速代謝者致命） |
| Morphine | 嗎啡錠、MST Continus | 強（基準） | 腎功能不全活性代謝物蓄積 |
| Oxycodone | 疼始康定 OxyContin | 強 | 口服吸收佳 |
| Oxycodone/Naloxone | Targin | 強 | 加入 Naloxone 減少便秘 |
| Fentanyl | 多瑞吉 Durogesic 貼片、針劑 | 極強（約嗎啡 100 倍） | 貼片不可剪開、加熱 |
| Buprenorphine | Norspan 貼片 | 部分促效 | 呼吸抑制有天花板 |
| Methadone | 美沙冬 | 強、半衰期極長 | 鴉片替代療法；蓄積性過量、QT 延長 |
| Naloxone | Narcan | 拮抗劑 | 過量解毒；通氣優先、會再昏迷 |

過量三徵：針狀瞳孔、意識抑制、呼吸抑制。便秘不會產生耐受，需預防性處理；與 BZD、酒精、Gabapentinoid 併用易致命。多數為管制藥品。

## 八、麻醉藥：靜脈誘導、吸入、局部麻醉

全身麻醉採多藥併用：誘導藥讓人失去意識、鴉片類止痛、肌肉鬆弛劑讓肌肉放鬆；局部麻醉藥則阻斷周邊神經鈉通道。

### 1. 靜脈誘導與鎮靜

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Propofol | 得普利麻 Diprivan | 最常用；起效與甦醒最快、止吐；血壓下降、呼吸暫停 |

| Isoflurane | 便宜；甦醒較慢 |
| 笑氣（N₂O） | 輔助用；氣胸、腸阻塞、中耳手術禁用 |

血／氣分配係數越小，誘導與甦醒越快。吸入麻醉藥與 Succinylcholine 可誘發惡性高熱，解毒劑為 Dantrolene。

### 3. 局部麻醉藥

| 學名 | 臺灣商品名 | 類別 | 重點 |
| --- | --- | --- | --- |
| Lidocaine | Xylocaine | Amide | 起效快；上限 4.5 mg/kg（含腎上腺素 7 mg/kg）；也是 Class IB 抗心律不整藥 |
| Bupivacaine | Marcaine | Amide | 長效；心毒性最強，上限 2.5 mg/kg |
| Ropivacaine | Naropin | Amide | 心毒性低於 Bupivacaine |
| Benzocaine、Tetracaine | 表面麻醉 | Ester | PABA 過敏；Benzocaine 可致變性血紅素血症 |

記憶法：藥名有兩個 i 為 Amide（肝代謝、過敏罕見），一個 i 為 Ester。全身毒性（LAST）「中樞症狀先於心臟」：口周麻木、耳鳴、金屬味 → 痙攣 → 心血管崩潰；處置為 BZD 控制痙攣與 20% 脂肪乳劑。

## 九、中樞神經興奮劑

中樞神經興奮劑提高大腦的多巴胺與正腎上腺素，或阻斷讓人想睡的腺苷，主要用於 ADHD 與猝睡症。臺灣治療 ADHD 的興奮劑以 Methylphenidate 為主；安非他命屬於第二級毒品，沒有上市藥品。

| 學名 | 臺灣商品名 | 機轉 | 重點 |
| --- | --- | --- | --- |
| Methylphenidate（速效） | 利他能 Ritalin | 多巴胺、正腎上腺素回收抑制劑（阻斷 DAT、NET） | ADHD、猝睡症；第三級管制藥品；作用約 3–4 小時 |
| Methylphenidate（長效） | 專思達 Concerta | 同上，滲透壓幫浦緩釋 | 一天一次；**不可剝開或咬碎** |
| Atomoxetine | 思銳 Strattera | 選擇性正腎上腺素回收抑制劑（非興奮劑） | 非管制藥品、濫用風險低；2–4 週以上才見效；有自殺意念警語 |
| Modafinil | 依院所而定 | 較弱的 DAT 抑制，另影響食慾素與組織胺系統 | 猝睡症、輪班工作睡眠障礙；會降低口服避孕藥效果；罕見 SJS |
| Pitolisant | 依院所而定 | H₃ 受體反向致效劑，增加腦中組織胺釋放 | 猝睡症；不是管制藥品 |
| Caffeine citrate | 多種 | 腺苷受體拮抗劑 | 早產兒呼吸暫停；成人咖啡因錠過量可致心律不整、低血鉀、癲癇 |
| Amphetamine（對照） | 臺灣未上市（Adderall） | 多巴胺、正腎上腺素**釋放劑**，同時阻斷回收 | 作用比 Methylphenidate 強；臺灣列為第二級毒品 |

為什麼興奮劑能治療 ADHD：ADHD 和前額葉的多巴胺與正腎上腺素訊號不足有關，前額葉負責專注與抑制衝動。藥物增強這些訊號，提高訊號雜訊比，人反而坐得住。一般人服用後作用方向相同，所謂「反常的鎮靜作用」是迷思；劑量太高時任何人都會亢奮。

常見副作用：食慾下降、失眠、頭痛、心跳與血壓輕度上升；兒童要追蹤身高體重；可能使抽動症惡化。禁止與 MAO 抑制劑併用（停用 MAOI 後至少隔 14 天），否則可能高血壓危象。

過量（擬交感神經中毒）：躁動、心跳快、血壓高、**體溫過高、大量出汗**、瞳孔放大、癲癇、橫紋肌溶解。和抗膽鹼中毒的差別是會出汗。處理：BZD 鎮靜與控制癲癇、積極降溫、監測心律；古柯鹼中毒合併 QRS 變寬時給碳酸氫鈉。

相關用藥：戒菸可用尼古丁替代療法（貼片、口嚼錠）、Varenicline（戒必適 Champix，α4β2 菸鹼受體部分致效劑，減輕戒斷與吸菸的快感）或 Bupropion（多巴胺與正腎上腺素回收抑制劑，會降低癲癇閾值）。減重藥 Phentermine 以釋放正腎上腺素為主，屬管制藥品，只能短期使用，副作用與興奮劑相同（心悸、失眠、血壓上升）。

## 十、骨骼肌鬆弛劑

「肌肉鬆弛劑」依作用點分三種：作用在**腦與脊髓**的中樞性肌肉鬆弛劑、直接作用在**肌肉細胞**的 Dantrolene，以及作用在**神經肌肉接合處**的肉毒桿菌毒素。它們和麻醉用的神經肌肉阻斷劑（見自律神經篇）不同：一般劑量不會讓人癱瘓，病人仍能自己呼吸。

| 類別 | 學名 | 臺灣商品名 | 機轉 | 用途與重點 |
| --- | --- | --- | --- | --- |
| 中樞性 | Baclofen | Lioresal | GABA-B 促效劑，抑制脊髓反射 | 脊髓損傷、多發性硬化症、腦性麻痺的痙攣；**不可突然停藥**（幻覺、癲癇，脊髓腔內幫浦中斷可致命）；腎功能差易蓄積 |
|   | Tizanidine | Sirdalud | 中樞 α₂ 促效劑 | 痙攣；嗜睡、低血壓；與 Fluvoxamine、Ciprofloxacin 併用時濃度大增 |
|   | Eperisone | 妙納 Myonal | 抑制脊髓反射，並輕度擴張血管 | **臺灣門診腰痠背痛最常用**；嗜睡較少 |
|   | Cyclobenzaprine | 依院所而定 | 結構類似三環抗鬱劑 | 急性肌肉痙攣；口乾、嗜睡等抗膽鹼副作用；禁與 MAOI 併用 |
|   | Chlorzoxazone、Orphenadrine | 多為複方 | 中樞抑制 | 常與 Acetaminophen 做成肌肉鬆弛複方止痛藥，要注意 Acetaminophen 重複 |
|   | Diazepam | Valium | 增強 GABA-A | 也有肌肉鬆弛作用；依賴性 |
| 直接作用於肌肉 | Dantrolene | Dantrium | 阻斷肌漿網 RyR1，減少鈣離子釋放 | 惡性高熱解毒劑；長期口服治療痙攣有肝毒性 |
| 作用於神經肌肉接合處 | Botulinum toxin A | 保妥適 Botox | 阻止神經末梢釋放 ACh | 局部注射治療痙攣、肌張力不全、慢性偏頭痛、膀胱過動、多汗；作用維持約 3–4 個月 |

共同注意：中樞性肌肉鬆弛劑與 BZD、鴉片類、酒精併用會加重嗜睡與呼吸抑制；老人容易頭暈跌倒。

## 十一、字尾辨識法

記住字尾，就能從沒看過的學名先猜出類別。

| 字尾 | 類別 | 例子 |
| --- | --- | --- |
| -azepam／-azolam | 苯二氮平類（BZD） | Lorazepam、Midazolam |
| -barbital | 巴比妥類 | Phenobarbital |
| -oxetine | SSRI／SNRI | Fluoxetine、Duloxetine |
| -triptyline／-ipramine | 三環抗鬱劑 | Amitriptyline、Imipramine |
| -peridol | 第一代抗精神病藥 | Haloperidol |
| -apine | 第二代抗精神病藥 | Olanzapine、Quetiapine、Clozapine |
| -idone | 第二代抗精神病藥 | Risperidone、Paliperidone |
| -racetam | SV2A 抗癲癇藥 | Levetiracetam |
| -giline | MAO-B 抑制劑 | Rasagiline、Selegiline |
| -capone | COMT 抑制劑 | Entacapone |
| -pezil／-stigmine | 膽鹼酯酶抑制劑 | Donepezil、Rivastigmine |
| -fentanil | Fentanyl 家族鴉片類 | Sufentanil、Remifentanil |
| -caine | 局部麻醉藥 | Lidocaine、Bupivacaine |
| -flurane | 吸入麻醉藥 | Sevoflurane、Desflurane |

例外：Zolpidem 與 Zopiclone 作用在 GABA-A 但不是 BZD；Carbamazepine 的 -azepine 不是抗精神病藥。

## 十二、重點總結與常見臨床情境

中樞神經藥物在臨床上最常出現於下列八個情境。

| 情境 | 常用藥物 |
| --- | --- |
| 癲癇重積狀態 | Lorazepam IV 或 Midazolam 肌注 → Levetiracetam、Valproate |
| 失眠 | CBT-I 優先；短期 Zolpidem 或 BZD |
| 憂鬱症、焦慮症 | SSRI（樂復得、立普能），初期可短暫併用 BZD |
| 急性躁動、譫妄 | 先找病因；Haloperidol 或第二代抗精神病藥；酒精戒斷用 BZD |
| 巴金森氏症 | 心寧美或美道普，搭配多巴胺促效劑或 MAO-B 抑制劑 |
| 阿茲海默症 | 愛憶欣、憶思能；中重度加 Memantine |
| 神經病變性疼痛 | 利瑞卡、千憂解；三叉神經痛用癲通 |
| 鴉片類過量 | 先通氣，再給 Naloxone，持續監測 |

五個最常考也最常出事的注意事項：

1. 鴉片類 + BZD + 酒精 + Gabapentinoid 會協同抑制呼吸，是過量致死的主要組合。
2. BZD、抗癲癇藥、左旋多巴、抗憂鬱藥都不可突然停藥。
3. Carbamazepine 用藥前驗 HLA-B*15:02；Valproate 避免用於育齡女性；Lamotrigine 必須緩慢加量。
4. 多種增加血清素的藥併用（SSRI、Tramadol、Triptan、DXM、MAOI）需警覺血清素症候群。
5. 老人與失智症病人避免抗膽鹼藥與 BZD；失智症老人使用抗精神病藥有增加死亡率的警語。
