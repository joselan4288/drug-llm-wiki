# 臺灣常用心血管藥物講義

Sep 27, 2026 · @Lan

本講義依「藥物類別」整理臺灣門診最常見的心血管藥物，共七大類，每項列出學名、臺灣常見商品名與臨床重點。中文商品名各廠牌不同，健保給付與供應可能異動，實際用藥以醫師處方與最新仿單為準。

建議讀法：先記第八節的字尾，再對照各節的商品名；遇到沒看過的學名，先用字尾猜類別。

## 一、降血壓類

高血壓第一線為 CCB、ARB、ACEI、Thiazide 利尿劑四類；β 阻斷劑退居第二線，除非合併冠心病、心衰竭或心律不整。

### 1. 鈣離子通道阻斷劑（CCB）

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Amlodipine | 脈優 Norvasc | 最常用，每日一次；副作用下肢水腫 |
| Felodipine | 普心寧 Plendil | — |
| Lercanidipine | 利壓 Zanidip | 水腫較少 |
| Nifedipine（緩釋） | 冠達悅歐樂 Adalat OROS | 只用緩釋型 |
| Diltiazem（non-DHP） | 合必爽 Herbesser | 控制心率、變異型心絞痛；心衰竭禁用 |
| Verapamil（non-DHP） | Isoptin | 同上；便秘明顯 |

### 2. 血管收縮素受體阻斷劑（ARB）

臺灣使用量最大的降壓藥類。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Valsartan | 得安穩 Diovan | — |
| Telmisartan | 必康平 Micardis | 半衰期長 |
| Olmesartan | 雅脈 Olmetec | — |
| Losartan | 可悅您 Cozaar | 可降尿酸，痛風者可考慮 |
| Candesartan | 博脈舒 Blopress | 心衰竭有實證 |
| Irbesartan | 安普諾維 Aprovel | — |

### 3. ACE 抑制劑（ACEI）

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Ramipril | 心達舒 Tritace | — |
| Enalapril | 悅您定 Renitec | — |
| Captopril | 刻甫定 Capoten | 短效 |
| Perindopril | 冠脈循 Coversyl | — |

ACEI 與 ARB 共同注意：ACEI 乾咳約 10–20%（ARB 不會）、高血鉀、血管性水腫；懷孕絕對禁用；兩者不可併用。

### 4. 利尿劑

| 學名 | 臺灣商品名 | 定位 |
| --- | --- | --- |
| Hydrochlorothiazide | 多見於複方 | 高血壓主力 |
| Indapamide | 鈉催離 Natrilix | 代謝影響較小 |
| Furosemide | 來適泄 Lasix | 心衰竭水腫、急性肺水腫，非高血壓首選 |
| Spironolactone | 安達通 Aldactone | 心衰竭支柱、頑固型高血壓；注意高血鉀 |
| Eplerenone | Inspra | 男性女乳症較少 |

Thiazide 會使尿酸上升，痛風者慎用。

不可突然停藥（反彈性心搏過速、心絞痛）；氣喘者慎用非選擇性藥物。

## 二、抗心絞痛類

這一類藥只緩解症狀；冠心病真正降低死亡率的是抗血小板藥與 statin（見第四、六節）。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Nitroglycerin 舌下錠 | Nitrostat | 急性緩解；0.4 mg 每 5 分鐘，最多 3 次 |
| Isosorbide mononitrate | 易速比 Imdur | 長期預防；需每日無藥期防耐受性 |
| Nicorandil | 喜革脈 Sigmart | 鉀通道開放 + 硝酸作用 |
| Trimetazidine | Vastarel | 代謝調節，不影響血壓心率 |
| Ivabradine | 康悅心 Procoralan | 只降心率不降血壓 |

硝酸類絕對禁忌：48 小時內用過威而鋼、犀利士等 PDE5 抑制劑（致命性低血壓）。收縮壓 <90 mmHg 或右心室梗塞亦不可使用。

## 三、抗心律不整類

臺灣最常用的是 Amiodarone（廣效）與 Propafenone（無結構性心臟病者）；β 阻斷劑是唯一被證實降低總死亡率的抗心律不整藥。

| 學名 | 臺灣商品名 | 分類 | 用途與重點 |
| --- | --- | --- | --- |
| Amiodarone | 臟得樂 Cordarone | Class III | 最常用廣效藥；追蹤甲狀腺、肺、肝、眼；注射只能用 D5W 稀釋 |
| Propafenone | Rytmonorm | Class IC | 無結構性心臟病的房顫、SVT；心肌梗塞後、心衰竭禁用 |
| Dronedarone | Multaq | Class III | 副作用較少；永久性房顫與心衰竭禁用 |
| Sotalol | Sotacor | Class II + III | 需監測 QT 與腎功能 |
| Mexiletine | Mexitil | Class IB | 心室性心律不整 |
| Digoxin | Lanoxin | 其他 | 房顫合併心衰竭或低血壓；治療窗窄 |
| Adenosine | Adenocor | 其他 | SVT 終止（急診）；快推加沖洗 |

β 阻斷劑（康肯等）與 Diltiazem、Verapamil 也常用於房顫心率控制，見第一節。

## 四、抗血小板類

動脈血栓（心肌梗塞、缺血性中風）以抗血小板為主；放支架後通常雙抗 6–12 個月，之後單用 Aspirin。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Aspirin | 伯基 Bokey | 低劑量 75–100 mg；冠心病與中風二級預防 |
| Clopidogrel | 保栓通 Plavix | 放支架後雙抗；Aspirin 不耐受時替代 |
| Ticagrelor | 百無凝 Brilinta | 急性冠心病；副作用為呼吸困難 |
| Prasugrel | Efient | 效力強；中風病史禁用 |

近期放支架者不可自行停用抗血小板藥，支架血栓比手術出血更致命。

## 五、抗凝血類

非瓣膜性心房顫動以 DOAC 為第一線；機械瓣膜與中重度二尖瓣狹窄只能用 Warfarin。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Apixaban | 艾必克凝 Eliquis | DOAC，出血風險較低 |
| Rivaroxaban | 拜瑞妥 Xarelto | DOAC |
| Edoxaban | 里先安 Lixiana | DOAC |
| Dabigatran | 普栓達 Pradaxa | DOAC；逆轉劑 Idarucizumab（Praxbind） |
| Warfarin | Coumadin | 需驗 INR；飲食維生素 K 需維持穩定 |
| Enoxaparin | 克立生 Clexane | 注射；住院預防、急性期、懷孕 |

抗凝血劑使用者服用丹參、當歸、銀杏等中藥或保健食品，出血風險會上升，應告知醫師。

## 六、降血脂類

冠心病病人 LDL 目標 <70 mg/dL，極高風險者 <55 mg/dL；以高強度 statin 為基礎。降低 LDL,斑塊的脂質核縮小、纖維帽變厚、發炎減少,斑塊變得**穩定、不容易破**;長期使用甚至可能讓斑塊稍微消退。

### 1. Statin（HMG-CoA 還原酶抑制劑）

抑制肝臟合成膽固醇的速率決定酵素 HMG-CoA 還原酶，肝細胞「缺膽固醇」後增加 LDL 受體，把血中 LDL 抓回肝臟。是唯一有大量降低死亡率證據的降血脂主力。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Atorvastatin | 立普妥 Lipitor | 高強度 statin（40–80 mg） |
| Rosuvastatin | 冠脂妥 Crestor | 高強度 statin（20–40 mg） |
| Simvastatin | 素果 Zocor | 中強度；CYP3A4 交互作用最多 |
| Pravastatin | 美百樂鎮 Mevalotin | 中強度；交互作用少 |

Statin 主要副作用為肌肉痠痛、CK 與肝指數上升，橫紋肌溶解很少見；紅麴成分與 lovastatin 相同，併用等於重複用藥。

### 2. 膽固醇吸收抑制劑

阻斷小腸的 NPC1L1 轉運蛋白，減少膽固醇吸收，肝臟同樣會增加 LDL 受體。單用約降 LDL 15–20%，通常與 statin 併用。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Ezetimibe | 怡妥 Ezetrol | statin 未達標時加上，或用於無法耐受 statin 者 |

### 3. PCSK9 抑制劑

PCSK9 原本會讓肝臟的 LDL 受體被分解；抑制它，LDL 受體就能重複使用，LDL 可在 statin 之外再降約五到六成。用於 statin 加 Ezetimibe 仍未達標的高風險病人，全部是皮下注射，健保條件嚴格。

| 學名 | 臺灣商品名 | 類型 | 重點 |
| --- | --- | --- | --- |
| Evolocumab | 瑞百安 Repatha | 單株抗體 | 每 2 週或每月注射 |
| Alirocumab | Praluent | 單株抗體 | 每 2 週或每月注射 |
| Inclisiran | Leqvio | 小干擾 RNA（siRNA） | 減少肝臟製造 PCSK9；起始後每半年注射一次；給付以最新規定為準 |

### 4. Fibrate（主降三酸甘油酯）

活化 PPARα，增加脂蛋白脂解酶，加速分解三酸甘油酯；HDL 輕微上升，對 LDL 效果有限。主要用於三酸甘油酯 ≥500 mg/dL（預防胰臟炎），或 statin 治療後三酸甘油酯仍高者。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Fenofibrate | 力平之 Lipanthyl | 與 statin 併用較安全；可能使肌酸酐上升、增加膽結石 |
| Gemfibrozil | Lopid | 避免與 statin 併用（肌肉病變、橫紋肌溶解風險高） |

## 七、心衰竭第四支柱：SGLT2 抑制劑

原為降血糖藥，現已證實不論有無糖尿病都能降低心衰竭住院與心血管死亡。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Dapagliflozin | 福適佳 Forxiga | 心衰竭、慢性腎臟病皆有適應 |
| Empagliflozin | 恩排糖 Jardiance | 同上 |

HFrEF 四大支柱：ARNI（健安心）+ β 阻斷劑（康肯、Dilatrend、Betaloc ZOK）+ 醛固酮拮抗劑MRA:Spironolactone（安達通）+ SGLT2 抑制劑。利尿劑只改善症狀，不算支柱。

## 八、字尾辨識法

記住字尾，就能從沒看過的學名先猜出類別。

| 字尾 | 類別 | 例子 |
| --- | --- | --- |
| -dipine（-地平） | DHP 型 CCB | Amlodipine |
| -sartan（-沙坦） | ARB | Telmisartan |
| -pril（-普利） | ACEI | Ramipril |
| -olol（-洛爾） | β 阻斷劑 | Bisoprolol |
| -statin（-他汀） | 降血脂 | Atorvastatin |
| -gliflozin（-格列淨） | SGLT2 抑制劑 | Dapagliflozin |
| -xaban（-沙班） | Xa 抑制劑 | Apixaban |
| -grel（-格雷） | P2Y12 抗血小板 | Clopidogrel |
| -zosin（-唑嗪） | α₁ 阻斷劑 | Doxazosin |
| -fibrate／-fibrozil | Fibrate（降三酸甘油酯） | Fenofibrate、Gemfibrozil |
| -cumab | PCSK9 單株抗體 | Evolocumab、Alirocumab |

例外：Verapamil 與 Diltiazem 也是 CCB，但沒有 -dipine 字尾；Carvedilol 是 α+β 阻斷劑，不是 CCB。

## 九、重點總結與常見處方組合

臺灣門診心血管處方大多是下列五組組合。

| 情境 | 常見組合 |
| --- | --- |
| 高血壓 | 脈優 + 必康平或雅脈；或複方易安穩、倍必康平 |
| 冠心病長期用藥 | 伯基 + 立普妥或冠脂妥，必要時加康肯與 ACEI/ARB |
| 放支架後 | 伯基 + 保栓通或百無凝（雙抗 6–12 個月） |
| 心房顫動 | 抗凝：艾必克凝、拜瑞妥或里先安；心率：康肯 |
| 心衰竭（HFrEF） | 健安心 + 康肯 + 安達通 + 福適佳，水腫時加來適泄 |

五個最常考也最常出事的注意事項：

1. ACEI 與 ARB 懷孕禁用，且兩者不可併用。
2. β 阻斷劑不可突然停藥。
3. 硝化甘油與 PDE5 抑制劑（威而鋼類）絕對不可併用。
4. NSAID + ACEI/ARB + 利尿劑「三重打擊」易造成急性腎損傷。
5. Diltiazem、Verapamil 在心衰竭（HFrEF）禁用。
