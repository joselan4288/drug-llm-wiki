# 高血鉀與慢性腎臟病用藥

> 出自〈泌尿系統〉講義第六節〔08-urinary#六〕。本頁由 `compile_wiki.py` 自動產生，內容與原講義相同。

腎臟衰竭時排不掉鉀與磷，也無法製造紅血球生成素、活化維生素 D。洗腎病人錯過洗腎後出現無力、心搏過緩，要先想到**高血鉀**。

## 1. 高血鉀急救：穩定心臟 → 把鉀推進細胞 → 排出體外

| 步驟 | 藥物 | 機轉 | 起效 | 重點 |
| --- | --- | --- | --- | --- |
| 1. 穩定心臟 | 葡萄糖酸鈣或氯化鈣 | 穩定心肌細胞膜，**不會降低血鉀** | 1–3 分鐘 | 心電圖有變化（T 波高尖、QRS 變寬）時最先給 |
| 2. 把鉀推進細胞 | 胰島素＋葡萄糖 | 活化鈉鉀幫浦 | 15–30 分鐘 | 注意低血糖 |
|   | Salbutamol 霧化 | β₂ 活化鈉鉀幫浦 | 15–30 分鐘 | 心悸、手抖 |
|   | 碳酸氫鈉 | 鹼化使鉀進入細胞 | — | 主要用於合併代謝性酸中毒 |
| 3. 排出體外 | Furosemide | 腎臟排鉀 | 數小時 | 腎臟仍有功能時才有效 |
|   | Polystyrene sulfonate（Kalimate、Kayexalate）、Patiromer、Sodium zirconium cyclosilicate（Lokelma） | 在腸道交換鉀離子後隨糞便排出 | 數小時 | 新藥起效較快、腸胃副作用較少 |
|   | 洗腎 | 直接清除 | 最確實 | 腎衰竭或藥物無效時 |

## 2. 慢性腎臟病與洗腎常用藥

| 問題 | 學名 | 臺灣商品名 | 機轉 | 重點 |
| --- | --- | --- | --- | --- |
| 高血磷 | 碳酸鈣、醋酸鈣 | 多種 | 在腸道結合食物中的磷 | **要隨餐吃**；可能高血鈣 |
|   | Sevelamer | Renvela | 不含鈣的磷結合劑 | 隨餐；便秘、脹氣 |
|   | Lanthanum carbonate | Fosrenol | 不含鈣的磷結合劑 | 隨餐嚼碎服用 |
| 續發性副甲狀腺亢進 | Cinacalcet | 依院所而定 | 擬鈣劑：讓副甲狀腺「以為」血鈣夠高，減少 PTH | 低血鈣、噁心 |
|   | Calcitriol | 羅鈣全 Rocaltrol | 活性維生素 D | 追蹤血鈣與血磷（內分泌篇） |
| 貧血 | Epoetin、Darbepoetin | Eprex、Aranesp | 補充紅血球生成素 | 先補足鐵；血紅素不宜拉太高（血液篇） |

腎臟病人要避免或減量的藥：NSAID、含鎂或鋁的制酸劑與瀉藥、磷酸鈉灌腸劑、Meperidine、Metformin（依腎功能）、多數抗生素與 DOAC（依腎功能調整）。

## 本頁藥物
