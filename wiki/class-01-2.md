# 膽鹼激性促效劑與膽鹼酯酶抑制劑

> 出自〈自律神經〉講義第二節〔01-autonomic#二〕。本頁由 `compile_wiki.py` 自動產生，內容與原講義相同。

這類藥增加 ACh 的作用：直接促效劑假扣 ACh，膽鹼酯酶抑制劑則阻止 ACh 被分解。副作用即副交感過度活化：流涎、腹瀉、心跳慢、支氣管收縮。

## 1. 直接促效劑

| 學名 | 臺灣商品名 | 用途與重點 |
| --- | --- | --- |
| Bethanechol | Urecholine | 術後或神經性尿滯留；氣喘、尿路或腸道機械性阻塞、消化性潰瘍、心搏過緩禁用 |
| Pilocarpine（眼藥水） | Isopto Carpine | 閉角性青光眼、縮瞳 |
| Pilocarpine（口服） | Salagen | 乾燥症、放療後口乾 |

## 2. 可逆性膽鹼酯酶抑制劑

| 學名 | 臺灣商品名 | 用途與重點 |
| --- | --- | --- |
| Neostigmine | Vagostigmin | 逆轉非去極化型肌肉鬆弛劑；須併用 Glycopyrrolate 或 Atropine |
| Pyridostigmine | Mestinon | 重症肌無力長期治療 |
| Donepezil | 愛憶欣 Aricept | 阿茲海默症；注意心搏過緩 |
| Rivastigmine | 憶思能 Exelon | 阿茲海默症、巴金森氏症失智；有貼片 |
| Galantamine | 利憶靈 Reminyl | 阿茲海默症 |
| Physostigmine | —（急診專案） | 抗膽鹼中毒的解毒劑；可進腦；三環抗鬱劑中毒禁用 |

## 3. 不可逆性抑制劑（中毒）

有機磷農藥與神經毒劑與膽鹼酯酶共價結合並「老化」，無醫療用途。表現為 SLUDGE（流涎、流淚、排尿、腹瀉、腸胃不適、嘔吐）加上縮瞳、心搏過緩、支氣管分泌物暴增、支氣管痙攣；菸鹼型作用另有肌肉顫動、無力，嚴重時呼吸肌麻痺；處置為大劑量 Atropine（終點是分泌物乾）加 Pralidoxime（2-PAM），2-PAM 須在酵素老化前及早給予。
