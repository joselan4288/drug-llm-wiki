# 抗感染治療的共同原則

> 出自〈抗感染 I：抗細菌藥物〉講義第七節〔11-antibacterial#七〕。本頁由 `compile_wiki.py` 自動產生，內容與原講義相同。

| 原則 | 內容 |
| --- | --- |
| 先採檢再給藥 | 血液培養、尿液培養、痰液培養應在第一劑抗生素前採檢，但**敗血症與細菌性腦膜炎不可因採檢延誤給藥**（敗血性休克建議 1 小時內給藥） |
| 經驗性治療與目標治療 | 先依感染部位、病人風險、當地抗藥性選擇廣效藥；培養結果出來後**降階**成窄效藥 |
| 療程 | 許多感染的療程已縮短（例如社區型肺炎 5–7 天、腎盂腎炎 7–14 天），不是「一定要吃滿兩週」；但結核、骨髓炎、心內膜炎需長療程 |
| 依腎功能調整 | 多數 β-內醯胺類、Vancomycin、胺基糖苷類、Fluoroquinolone、Ethambutol 經腎排除；Ceftriaxone、Moxifloxacin、Doxycycline、Clindamycin、Linezolid 多不需調整 |
| 懷孕相對安全 | 青黴素類、頭孢菌素類、Azithromycin、Clindamycin、Fosfomycin、Nitrofurantoin（足月除外） |
| 懷孕避免 | 四環黴素類、Fluoroquinolone、胺基糖苷類、TMP-SMX（懷孕早期與晚期）、Chloramphenicol |
| 困難梭狀桿菌高風險 | Clindamycin、Fluoroquinolone、第三代以後頭孢菌素、Carbapenem；治療首選**口服 Vancomycin 或 Fidaxomicin** |
| 抗生素管理 | 病毒性上呼吸道感染、急性支氣管炎不需抗生素；不完整或不必要的使用會促進抗藥性 |
