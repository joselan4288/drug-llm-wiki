# 造血藥

> 出自〈血液、發炎與痛風〉講義第五節〔05-blood-inflammation#五〕。本頁由 `compile_wiki.py` 自動產生，內容與原講義相同。

貧血先分類再補充：小球性（MCV 低）多為缺鐵，大球性（MCV 高）多為缺 B12 或葉酸，慢性腎病則是缺乏紅血球生成素（EPO）。地中海型貧血在臺灣常見，也是小球性，但**不缺鐵就不要補鐵**。

| 學名 | 臺灣商品名 | 用途 | 重點 |
| --- | --- | --- | --- |
| Ferrous sulfate（硫酸亞鐵）、Ferrous fumarate（延胡索酸亞鐵）：口服鐵劑 | 多種學名藥 | 缺鐵性貧血 | 空腹加維生素 C 吸收較好；與制酸劑、四環黴素、喹諾酮間隔 2 小時；便秘、黑便；隔天服用吸收反而較好；誤食過量用 Deferoxamine |
| Iron sucrose（蔗糖鐵）、Ferric carboxymaltose（羧基麥芽糖鐵）：靜脈鐵劑 | Venofer、Ferinject | 口服無效或不耐受、洗腎病人 | 少數過敏；Ferric carboxymaltose 可能低血磷 |
| Cyanocobalamin、Mecobalamin（維生素 B12） | 彌可保 Methycobal | 惡性貧血、胃切除後、長期 Metformin 或素食 | 缺乏內在因子者需肌肉注射（或高劑量口服）；缺乏會造成神經病變 |
| Folic acid（葉酸） | 多種學名藥 | 葉酸缺乏、懷孕前預防神經管缺陷 | 懷孕前至少一個月開始每天 0.4 mg；**單補葉酸可掩蓋 B12 缺乏，神經傷害繼續惡化** |
| Leucovorin（甲醯四氫葉酸） | 多種學名藥 | Methotrexate 中毒解毒、化療輔助 | 可繞過二氫葉酸還原酶 |
| Epoetin alfa、Darbepoetin、Methoxy PEG-epoetin beta（紅血球生成素類） | Eprex、Aranesp、Mircera | 慢性腎病貧血、部分化療貧血 | 先補足鐵；血紅素不宜拉太高（約≤ 11–12 g/dL），否則中風與血栓風險上升；高血壓；常被運動員濫用 |
| Filgrastim（白血球生長激素 G-CSF） | Neupogen 等 | 化療後嗜中性球減少、幹細胞動員 | 骨頭痠痛；長效型為 Pegfilgrastim |
| Eltrombopag（血小板生成素受體致效劑） | Revolade | 免疫性血小板缺乏症（ITP） | 肝毒性；與鈣、鐵等礦物質間隔服用 |

其他維生素：脂溶性維生素（A、D、E、K）會在體內累積，過量風險較高；水溶性維生素多餘的多半會排出，但 B3 與 B6 仍可能中毒。B12 與葉酸見上表。

| 維生素 | 缺乏表現 | 過量風險與重點 |
| --- | --- | --- |
| A | 夜盲、乾眼 | **致畸胎**（孕婦避免高劑量，維甲酸類藥物 Isotretinoin 同理）、肝毒性、顱內壓上升 |
| D | 佝僂病、骨軟化 | 高血鈣：噁心、多尿、腎結石、心律不整 |
| E | 少見，神經病變 | 高劑量增加出血，與 Warfarin 併用要小心 |
| K | 出血；新生兒出生時常規注射預防出血 | 拮抗 Warfarin 的效果 |
| B1（Thiamine） | 腳氣病、Wernicke 腦病變（酒精使用障礙） | 幾乎無毒；酒精使用障礙者應在給葡萄糖前後盡早補充 |
| B3（菸鹼酸） | 癩皮病（皮膚炎、腹瀉、失智） | 臉潮紅、肝毒性、血糖與尿酸上升 |
| B6（Pyridoxine） | 周邊神經病變；服用 Isoniazid 者常需補充 | 長期高劑量造成感覺神經病變 |
| C | 壞血病 | 草酸鈣腎結石；G6PD 缺乏者大劑量靜脈注射可能溶血 |

## 本頁藥物

Ferrous sulfate、Ferrous fumarate、Ferric carboxymaltose、Cyanocobalamin、Mecobalamin、Folic acid、Leucovorin、Epoetin alfa、Darbepoetin、Methoxy、Filgrastim、Eltrombopag、Thiamine、Pyridoxine
