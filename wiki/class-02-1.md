# 降血壓類

> 出自〈心血管〉講義第一節〔02-cardiovascular#一〕。本頁由 `compile_wiki.py` 自動產生，內容與原講義相同。

高血壓第一線為 CCB、ARB、ACEI、Thiazide 利尿劑四類；β 阻斷劑退居第二線，除非合併冠心病、心衰竭或心律不整。

## 1. 鈣離子通道阻斷劑（CCB）

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Amlodipine | 脈優 Norvasc | 最常用，每日一次；副作用下肢水腫 |
| Felodipine | 普心寧 Plendil | — |
| Lercanidipine | 利壓 Zanidip | 水腫較少 |
| Nifedipine（緩釋） | 冠達悅歐樂 Adalat OROS | 只用緩釋型 |
| Diltiazem（non-DHP） | 合必爽 Herbesser | 控制心率、變異型心絞痛；心衰竭禁用 |
| Verapamil（non-DHP） | Isoptin | 同上；便秘明顯 |

## 2. 血管收縮素受體阻斷劑（ARB）

臺灣使用量最大的降壓藥類。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Valsartan | 得安穩 Diovan | — |
| Telmisartan | 必康平 Micardis | 半衰期長 |
| Olmesartan | 雅脈 Olmetec | — |
| Losartan | 可悅您 Cozaar | 可降尿酸，痛風者可考慮 |
| Candesartan | 博脈舒 Blopress | 心衰竭有實證 |
| Irbesartan | 安普諾維 Aprovel | — |

## 3. ACE 抑制劑（ACEI）

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Ramipril | 心達舒 Tritace | — |
| Enalapril | 悅您定 Renitec | — |
| Captopril | 刻甫定 Capoten | 短效 |
| Perindopril | 冠脈循 Coversyl | — |

ACEI 與 ARB 共同注意：ACEI 乾咳約 10–20%（ARB 不會）、高血鉀、血管性水腫；懷孕絕對禁用；兩者不可併用。

## 4. 利尿劑

| 學名 | 臺灣商品名 | 定位 |
| --- | --- | --- |
| Hydrochlorothiazide | 多見於複方 | 高血壓主力 |
| Indapamide | 鈉催離 Natrilix | 代謝影響較小 |
| Furosemide | 來適泄 Lasix | 心衰竭水腫、急性肺水腫，非高血壓首選 |
| Spironolactone | 安達通 Aldactone | 心衰竭支柱、頑固型高血壓；注意高血鉀 |
| Eplerenone | Inspra | 男性女乳症較少 |

Thiazide 會使尿酸上升，痛風者慎用。

## 5. β 阻斷劑

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Bisoprolol | 康肯 Concor | 心衰竭三種有實證之一 |
| Metoprolol succinate | Betaloc ZOK | 心衰竭用須緩釋型 |
| Carvedilol | Dilatrend | 兼 α 阻斷，心衰竭用 |
| Propranolol | 恩特來 Inderal | 甲亢、震顫、偏頭痛 |
| Atenolol | Tenormin | 較舊 |

不可突然停藥（反彈性心搏過速、心絞痛）；氣喘者慎用非選擇性藥物。
