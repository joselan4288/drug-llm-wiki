# 抗凝血類

> 出自〈心血管〉講義第五節〔02-cardiovascular#五〕。本頁由 `compile_wiki.py` 自動產生，內容與原講義相同。

非瓣膜性心房顫動以 DOAC 為第一線；機械瓣膜與中重度二尖瓣狹窄只能用 Warfarin。

| 學名 | 臺灣商品名 | 重點 |
| --- | --- | --- |
| Apixaban | 艾必克凝 Eliquis | DOAC，出血風險較低 |
| Rivaroxaban | 拜瑞妥 Xarelto | DOAC |
| Edoxaban | 里先安 Lixiana | DOAC |
| Dabigatran | 普栓達 Pradaxa | DOAC；逆轉劑 Idarucizumab（Praxbind） |
| Warfarin | Coumadin | 需驗 INR；飲食維生素 K 需維持穩定 |
| Enoxaparin | 克立生 Clexane | 注射；住院預防、急性期、懷孕 |

抗凝血劑使用者服用丹參、當歸、銀杏等中藥或保健食品，出血風險會上升，應告知醫師。
